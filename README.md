One line, the funniest excuse an AI agent gives after failing a task:

> The document is ready — in a folder I cannot open, on a drive I cannot see, in a format I cannot read.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validated to 1–200 characters, a single line, and not only whitespace.
